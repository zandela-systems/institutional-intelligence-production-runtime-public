# Public Architecture

IIPR is being built from a typed constitutional kernel outward.

## Governing model

```text
candidate institutional record
→ typed structural validation
→ evidence association
→ review
→ human authority
→ canonical institutional state
→ later publication/intelligence layers
```

## Current foundation

The public architectural focus is:

- strict typed records;
- stable IDs/digests;
- canonical serialization;
- versioned state;
- deterministic validators;
- evidence-preserving build workflow;
- explicit human ratification.

Later research, EDI, monitoring, provider, and publication capabilities are intentionally outside the current kernel claim.

## Public boundary

This summary excludes private schemas where sensitive, internal prompts, raw build traces, credentials, and unpublished implementation mechanics.
