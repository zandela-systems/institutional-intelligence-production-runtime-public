# Demo Walkthrough — Candidate Record to Canonical Institutional State

## Goal

Illustrate the authority separation built into IIPR.

## Step 1 — Construct a typed candidate

A record is created using the B1 typed model contracts.

Structural validation can verify:

- ID form;
- timestamp form;
- enum/domain constraints;
- canonical serialization;
- digest integrity;
- local consistency rules.

## Step 2 — Produce evidence

Tests and doctor may demonstrate that the candidate satisfies B1 structural invariants.

That evidence does **not** itself grant authority.

## Step 3 — Review

Adversarial/independent review evaluates defects and records finding dispositions.

A passing test suite does not automatically erase open review findings.

## Step 4 — Human authority

Consequential institutional truth requires an explicit human authority event.

## Step 5 — Canonical state

Only after the required authority transition can the record be treated as canonical institutional state.

## Key lesson

```text
valid structure ≠ true evidence ≠ authorized state ≠ publication-safe output
```

That separation is the core of the B1 constitutional model.
