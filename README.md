# Institutional Intelligence-Production Runtime

**A governed runtime foundation for institutional intelligence production under explicit human authority.**

Institutional Intelligence-Production Runtime (IIPR) is being built around a constitutional principle:

> **Human authority is the root of designated consequential institutional truth. Runtime structure preserves and enforces that authority; models do not inherit it.**

## What IIPR is

IIPR is a governed foundation for producing institutional intelligence with explicit state, evidence, provenance, authority, and publication boundaries.

The current implementation is intentionally narrow: it establishes the typed constitutional kernel on which later intelligence-production capabilities can be built.

## Current kernel focus

The present foundation emphasizes:

- strict typed records;
- immutable/frozen canonical models;
- canonical serialization;
- stable identifiers and digests;
- explicit versioning;
- machine-readable state;
- deterministic validation;
- evidence-preserving build workflows;
- human ratification boundaries.

## What it is not yet

The current kernel should not be mistaken for the complete future system.

It is **not yet**:

- an autonomous research engine;
- an EDI production engine;
- an evidence-truth authenticator;
- a publication engine;
- a monitoring system;
- a provider/model orchestration layer;
- a fully autonomous institutional agent.

Those capabilities belong to later authorized gates.

## Constitutional model

The runtime is designed so that consequential state does not become authoritative merely because a model generated it or a test passed.

```text
candidate
→ typed validation
→ evidence
→ review
→ human authority
→ canonical institutional state
```

Passing structural validation proves structure. It does not, by itself, prove evidence truth or publication safety.

## Why this matters

Institutional intelligence requires more than good model output.

It requires a system that can answer:

- What is the authoritative record?
- What evidence supports it?
- What changed?
- Who or what proposed the change?
- What validation occurred?
- Who had authority to ratify it?
- Is it safe to publish?

IIPR is the runtime foundation for making those questions first-class.

## Public boundary

This repository is a sanitized public showcase derived from a private canonical repository.

It excludes credentials, sensitive evidence, internal prompts, raw agent traces, private implementation details, and any state that has not crossed the publication boundary.
